# LastDatabase HubSpot Integration

LastDatabase supports an integration workflow for sending eligible business contacts to HubSpot CRM.

## Official Documentation

https://lastdatabase.com/docs/hubspot-integration

## Overview

The integration uses an authorization workflow between a LastDatabase customer account and HubSpot.

Supported workflows can include selecting eligible contacts in LastDatabase and delivering them to the connected HubSpot account.

For current behavior, requirements, field mapping, authorization, and troubleshooting, use the official documentation above.
