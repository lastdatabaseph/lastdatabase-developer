# Security Policy

## Reporting a Security Issue

Do not disclose security vulnerabilities through public GitHub issues.

Use the official LastDatabase contact channels:

https://lastdatabase.com/contact

## Credentials

Never publish:

- API keys
- access tokens
- OAuth credentials
- session credentials
- customer authentication information
- database credentials
- downloaded customer data
- private lead records

If a credential may have been exposed, stop using it and follow the appropriate credential-rotation or support procedure.
