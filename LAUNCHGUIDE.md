# LastDatabase MCP Server

## Name

LastDatabase — B2B & B2C Lead Discovery

## Description

LastDatabase is a remote Model Context Protocol (MCP) server
for AI-powered business contact discovery and consumer email
lead research.

It enables compatible AI assistants to search lead datasets,
identify relevant business contacts, and support sales prospecting,
market research, and marketing workflows.

## Website

https://lastdatabase.com

## GitHub Repository

## MCP Server Endpoint

https://lastdatabase.com/mcp

## Server Type

Remote MCP Server

## Transport

Streamable HTTP

## Authentication

OAuth 2.0

Users authorize their MCP-compatible client through their
LastDatabase account.

No local installation is required for the hosted MCP server.

## Setup Requirements

1. Create a LastDatabase account.
2. Open an MCP-compatible client supporting remote servers.
3. Add the MCP endpoint:
   https://lastdatabase.com/mcp
4. Complete OAuth 2.0 authorization.
5. Use the tools available to your account.

No manually configured API key or environment variable is
required for the standard OAuth connection.

## Features

- B2B business contact discovery
- Consumer email lead discovery
- Country-based lead searches
- State and city filtering
- Industry filtering
- Job title filtering
- Company-based prospect research
- Technology-based prospect research
- Masked contact previews where supported
- Account-based access controls
